EDIT Profile/settings

sequenceDiagram
    actor User
    participant UI as Mobile App (UI)
    participant PC as ProfileController
    participant DB as DatabaseManager

    User->>UI: Navigate to "Profile" screen
    UI-->>User: Display profile picture, name, email and account statistics
    UI-->>User: Display settings options (Notifications, Currency, Language, Appearance)
    User->>UI: Tap on a setting (e.g. "Currency")
    UI-->>User: Display list of available options
    User->>UI: Select new option (e.g. "EUR")
    UI->>PC: saveSettings(userId, settings)
    PC->>PC: validateInput()

    alt [Invalid selection]
        PC-->>UI: HandleError(msg)
        UI-->>User: Display error message
    else [Valid selection]
        PC->>DB: method(type)
        DB-->>PC: Success
        PC->>UI: updateProfile(userId, data)
        UI->>UI: updateDisplay()
        UI-->>User: Return to Profile screen, new setting applied across app
    end
